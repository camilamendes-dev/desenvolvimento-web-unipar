# Clube do Salsichinha — atv4 (React + Vite)

Refatoração do blog da atv1 para React, com componentes e props.

## Componentes
- `App`: guarda os dados do post e compõe a página
- `Header`: título principal do blog
- `Navigation`: links de navegação
- `Article`: exibe o post (título, autor, data, conteúdo) via props
- `Sidebar`: lista de posts relacionados
- `Footer`: direitos autorais

## Como executar
```bash
npm install
npm run dev
```
